# Gitignore 速记

作用：匹配到的**未跟踪**文件/目录不进入版本管理。

## 基本写法

```gitignore
# 具体文件（相对仓库根）
backend-init.log
.ai_-show/foo.txt          # 子路径写真实相对路径

# 目录（末尾 / 表示只匹配目录）
.codegraph/
.agents/

# 通配
*.log                         # 任意层级的 .log 文件
target/                       # 任意层级的 target 目录

# 先忽略再放行
*.env
!.env.example                 # 例外：仍可跟踪
```

## `.` 和 `/` 别搞混

| 符号     | 含义                                             |
| -------- | ------------------------------------------------ |
| 开头 `.` | 文件名的一部分（隐藏文件），如 `.agents`、`.env` |
| 开头 `/` | 锚定到 `.gitignore` 所在目录（通常是仓库根）     |
| 结尾 `/` | 只匹配目录，不匹配同名文件                       |

## `/target` 三种对比

| 写法       | 效果                                                         |
| ---------- | ------------------------------------------------------------ |
| `/target/` | 只忽略根下名为 `target` 的**目录**                           |
| `target/`  | 任意层级名为 `target` 的**目录**                             |
| `/target`  | 只匹配根下名为 `target` 的**文件或目录**（不含 `target.txt`） |



## 生效与提交

- 本地写好立刻生效，**不必提交**也能用

- **要团队共享规则，需要提交** `.gitignore`

- 已被跟踪的文件再写进 ignore **无效**，需先：

  ```bash
  git rm --cached path/to/file
  ```
