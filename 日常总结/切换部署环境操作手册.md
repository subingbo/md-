# 切换部署环境操作手册

本文档说明如何在 **公司 Docker 测试环境** 与 **甲方 K8s 环境** 之间切换配置、打包与发布。

> 不在本地 IDEA 启动项目；两个环境均通过部署时注入 `SPRING_PROFILES_ACTIVE` 激活对应 profile。

---

## 1. 背景与适用范围

### 1.1 两套环境

| 环境             | 运行方式         | Spring Profile | Nacos 地址          | 命名空间                               |
| ---------------- | ---------------- | -------------- | ------------------- | -------------------------------------- |
| 公司 Docker 测试 | Docker Compose   | `test`         | `nacos:8848`        | `da256a30-ac68-4215-962c-a4e99c605f32` |
| 甲方 K8s         | Pod / Deployment | `k8s`          | `cspon-config:8848` | public（空）                           |

### 1.2 纳入管理的 11 个服务

| 模块               | `spring.application.name` |
| ------------------ | ------------------------- |
| yudao-gateway      | `gjy-gateway-server`      |
| yudao-module-infra | `gjy-infra-server`        |
| analysis-service   | `gjy-analysis-service`    |
| community-service  | `gjy-community-service`   |
| construct-service  | `gjy-construct-service`   |
| detail-service     | `gjy-detail-service`      |
| infra-service      | `gjy-infra-service`       |
| monitor-service    | `gjy-monitor-service`     |
| plan-service       | `gjy-plan-service`        |
| stat-service       | `gjy-stat-service`        |
| trans-service      | `gjy-trans-service`       |

不含 `yudao-module-system` 及其他未上线模块。

## 2. 配置分层

```
部署环境变量 SPRING_PROFILES_ACTIVE=test | k8s
        ↓
classpath application-{profile}.yaml    → 薄层：Nacos 地址/命名空间/账号 + 主系统鉴权
        ↓
Nacos common.yaml                       → 主体：DB、Redis、连接池、yudao 公共项
Nacos {app}-{profile}.yaml              → 服务级覆盖（多数为空）
```

### 2.1 classpath 里存什么（打进 jar）

**`application-test.yaml`（公司 Docker）：**

- `spring.cloud.nacos.server-addr: nacos:8848`
- `spring.cloud.nacos.discovery.namespace` / `config.namespace`: `da256a30-ac68-4215-962c-a4e99c605f32`
- gateway/gzmap 额外 import `application-gzmap-main-system-gateway.yaml`

**`application-k8s.yaml`（甲方 K8s）：**

- `spring.cloud.nacos.server-addr: cspon-config:8848`
- namespace 留空（public）
- `spring.cloud.nacos.password: Nacos@2024`

**`application-gzmap-main-system-gateway.yaml`（`use-env.ps1` 打包前同步）：**

| 环境         | `gzmap.security.main-system.base-url` |
| ------------ | ------------------------------------- |
| company-test | `https://ghssjd.test.up.xc`           |
| client-k8s   | `https://ghjd.gzlpc.gov.cn`           |

### 2.2 Nacos 里存什么

路径：`config/environments/{company-test|client-k8s}/nacos/`

| 变量                     | company-test          | client-k8s                   |
| ------------------------ | --------------------- | ---------------------------- |
| DB                       | `kingbase:54321/test` | `TODO_KINGBASE_HOST`（待填） |
| Redis                    | `redis:6379`          | `cspon-redis:6379`           |
| `yudao.web.admin-ui.url` | 必填                  | 必填                         |

禁止写 `spring.data.redis.ssl: false`，见 [redis-spring-boot3-nacos-config.md](../redis-spring-boot3-nacos-config.md)。

## 4. 首次初始化

1. 编辑 `config/environments/client-k8s/nacos/common.yaml`，替换 `TODO_KINGBASE_HOST`、`TODO_DB_PASSWORD`
2. 导入 Nacos：

```powershell
.\config\scripts\nacos-import.ps1 company-test `
  -ServerAddr http://nacos:8848 `
  -Namespace da256a30-ac68-4215-962c-a4e99c605f32

.\config\scripts\nacos-import.ps1 client-k8s `
  -ServerAddr http://cspon-config:8848 `
  -Username nacos -Password 'Nacos@2024'
```

---

## 5. 切换环境完整流程

### 5.1 公司 Docker

```powershell
.\config\scripts\use-env.ps1 company-test
# 打包 / 构建镜像
.\config\scripts\nacos-import.ps1 company-test -ServerAddr http://nacos:8848 -Namespace da256a30-ac68-4215-962c-a4e99c605f32
# 环境变量 SPRING_PROFILES_ACTIVE=test（见 config/environments/company-test/deploy/env.example）
docker compose up -d --force-recreate
```

### 5.2 甲方 K8s

```powershell
.\config\scripts\use-env.ps1 client-k8s
# 打包 / 构建镜像
.\config\scripts\nacos-import.ps1 client-k8s -ServerAddr http://cspon-config:8848 -Username nacos -Password 'Nacos@2024'
# Deployment 环境变量 SPRING_PROFILES_ACTIVE=k8s（见 client-k8s/deploy/env.example）
kubectl rollout restart deployment/<deployment名> -n <namespace>
```

### 5.3 对比两套 common.yaml

```powershell
.\config\scripts\nacos-diff.ps1
```

- `gjy-detail-service-{test|k8s}.yaml`

## 7. 验证清单

- [ ] 日志：`The following 1 profile is active: "test"` 或 `"k8s"`
- [ ] 日志：`[Nacos Config] Load config[dataId=common.yaml] success`（infra/gzmap）
- [ ] Nacos 控制台对应命名空间下 DataId 非空
- [ ] 网关无 503，11 个服务已注册
- [ ] 甲方已弃用 `profile=test`，改为 `k8s`

## 8. 常见问题

| 现象                                 | 原因与处理                                                   |
| ------------------------------------ | ------------------------------------------------------------ |
| jar 里 `active: local` 却跑 test/k8s | 部署 `SPRING_PROFILES_ACTIVE` 覆盖默认值                     |
| 改 classpath 里 DB 无效              | DB 在 Nacos `common.yaml`，需 nacos-import 后重启            |
| Redis ssl 绑定失败                   | 删除 Nacos 中 `ssl: false`，见 redis 文档                    |
| 网关 503                             | 命名空间/profile 不一致，见 [部署改进建议](../数据/部署改进建议-2026-04-28.md) |
| 甲方仍用 test profile                | 改为 `k8s` 并导入 `*-k8s.yaml`                               |

## 9. 变更记录（2026-06）

| 变更                                 | 说明                            |
| ------------------------------------ | ------------------------------- |
| 新增 `config/environments/`          | 双环境 Nacos + 鉴权 Git 化      |
| 新增 `application-k8s.yaml`          | gateway、infra、9 gzmap         |
| 修正 gateway `application-test.yaml` | 由 cspon-config 改为 nacos:8848 |
| 基线去环境化                         | infra/gzmap 移除写死 Nacos 地址 |
| Profile 分离                         | Docker=`test`，甲方=`k8s`       |



| 优先级 | 来源                | 你项目里的例子                                      |
| :----- | :------------------ | :-------------------------------------------------- |
| 最高   | 命令行 `-D`         | `-Dspring.profiles.active=test`                     |
| 高     | 环境变量            | `SPRING_PROFILES_ACTIVE=test`（若没写 `-D` 也生效） |
| 中     | jar 内 profile 文件 | `application-test.yml`                              |
| 低     | jar 内基线          | `application.yml` 里的 `active: local`              |
| 远程   | Nacos 拉下来的配置  | `common.yaml` 等                                    |
